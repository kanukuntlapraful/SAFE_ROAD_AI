# Data collection

`data/raw/indian_roads_dataset.csv` is the 20,000-record road accident dataset supplied for issue #2. The raw CSV is included unchanged so later cleaning and analysis can be reproduced from the original input.

The records include location, date and time, road and traffic conditions, weather, accident cause and severity, casualty counts, and a risk score. The CSV header is the authoritative list of fields.

The source and collection method were not documented with the supplied file. Add that provenance here when it is available.
